# intermediation-cap

CAP-based service facade for the `modern-sap-lab` intermediation domain.

This repository will host the SAP Cloud Application Programming Model (CAP) layer used to expose and adapt services for external consumers while keeping the core intermediation business logic in ABAP Cloud / RAP.

## Status

Initial repository bootstrap.

## Architecture role

- External-facing service facade
- Consumer-oriented APIs
- Integration with RAP services
- SAP BTP / Cloud Foundry deployment target
- Clean Core side-by-side extension
